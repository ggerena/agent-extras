# AGENTS.md

Repository rules:

1. Keep this repository focused on reusable agent skills and small helper scripts.
2. Keep editable skill sources under `skills/`.
3. Do not add application code, heavy builds, generated artifacts, local backups, private memories, credentials, or machine-specific configuration.
4. Prefer simple, portable instructions and avoid hardcoded user paths.
5. Verify scripts with a dry run or safe local check before publishing changes.
